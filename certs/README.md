# 统一客户端信任文件

`trusted-ca.pem` 是公开证书合集，不含私钥，供所有盒子复用。当前包含公网 `47.111.133.127` 与内网 `172.21.30.204` 的既有 rttys 自签名证书；各服务器IP、端口和Token仍独立配置。

构建客户端包时自动复制为包内 `cert.pem`，安装后放到 `/etc/rtty/trusted-ca.pem`。保留包内旧文件名是为了兼容已有安装包结构。所有平台的客户端配置引用同一全局路径。

证书更新后重新构建并分发安装包。当前204证书有效期至2026-11-19，公网证书至2027-10-27。服务器证书仍须匹配实际IP/域名。此文件不涉及 Mender 的独立证书，也不是给服务器分发同一把私钥。
